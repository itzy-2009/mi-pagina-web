1. Inserción de Imágenes y Tablas

Ejemplos de sintaxis para incorporar recursos visuales y estructurar información en filas y columnas:

<!-- Cómo insertar una imagen -->
<img src="foto.jpg" alt="Imagen de práctica" width="300">

<!-- Cómo crear una tabla básica -->
<table border="1">
    <tr>
        <th>Columna 1</th>
        <th>Columna 2</th>
    </tr>
    <tr>
        <td>Dato A</td>
        <td>Dato B</td>
    </tr>
</table>

2. Hipervínculos (Enlaces)

Los hipervínculos se generan mediante la etiqueta <a> combinada con el atributo href para direccionar a otras páginas:

<!-- Enlace hacia otra página interna del proyecto -->
<a href="html-basico.html">Ir al módulo HTML Básico</a>

<!-- Enlace hacia una página de internet externa -->
<a href="https://www.google.com" target="_blank">Ir a Google</a>
