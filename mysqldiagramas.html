1. Diagrama Entidad-Relación (E-R)

Es un modelo conceptual que permite representar visualmente los componentes de un sistema y cómo se relacionan entre sí:

  • Entidades: Objetos o conceptos principales (ej. Alumnos, Cursos), representados en rectángulos.
  • Atributos: Características o propiedades de cada entidad (ej. nombre, edad, ID).
  • Relaciones: Vínculos lógicos entre las entidades, representados mediante rombos.

2. Modelo Relacional

Es la traducción técnica del diagrama E-R a un esquema tabular estructurado para el sistema de base de datos:

  • Llave Primaria (PK - Primary Key): Identificador único e irrepetible para cada registro dentro de una tabla.
  • Llave Foránea (FK - Foreign Key): Campo que establece un puente de relación directo conectando con la llave primaria de otra tabla.
