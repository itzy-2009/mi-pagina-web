1. ¿Cómo crear una página web básica?

Para crear una página web desde cero, se redacta el código en un editor de texto (como el Bloc de notas) y se guarda con la extensión .html (seleccionando "Todos los archivos" para evitar que se guarde como .txt). La estructura obligatoria que todo navegador lee es la siguiente:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi Página Web Escolar</title>
</head>
<body>
    <h1>Bienvenido a mi sitio web</h1>
    <p>Esta página fue creada por Karen Itzel (Grupo 506).</p>
</body>
</html>

2. Sintaxis Básica de HTML

HTML utiliza etiquetas (tags) delimitadas por corchetes angulares < > para indicar al navegador cómo mostrar la información:

  • <!DOCTYPE html>: Define que el documento es de HTML5.
  • <html>: Elemento raíz que envuelve toda la página.
  • <head>: Contiene la configuración de la página, codificación y el título de la pestaña.
  • <body>: Contiene todo el contenido visual que se muestra en pantalla.
  • <h1> a <h6>: Niveles de títulos y encabezados.
  • <p>: Define bloques de párrafos de texto.
  • <br>: Realiza un salto de línea individual.
